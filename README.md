# categories

Concept demo websites built for outreach to local business leads found via [gmaps-leads](../konkursi/gmaps-leads). Each subfolder is a standalone Next.js site, deployed as its own Vercel project (root directory set to the subfolder).

## Sites

- [`west-village-auto`](./west-village-auto) — West Village Auto Repair, Greenwich Village, NYC
- [`new-auto-tech`](./new-auto-tech) — New Auto Tech, Finsbury Park, London
- [`calis-auto-repair`](./calis-auto-repair) — Cali's Auto Repair & Diagnostics, Bronx, NYC
